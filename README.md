# Sanjib Academy

Welcome to **Sanjib Academy**!

## Overview

Sanjib Academy is a **TypeScript-based monorepo** that leverages the **TanStack ecosystem** across most of the application. The project is organized to promote code sharing, scalability, and maintainability.

## Tech Stack

- **TypeScript**
- **Monorepo Architecture**
- **TanStack Ecosystem**, including (where applicable):
  - TanStack Router
  - TanStack Query
  - TanStack Form
  - TanStack Table
  - Other TanStack libraries as needed

## Getting Started

If you're new to this project, **it's recommended to use Docker** for your development workflow.

> **Recommendation:** Use **Docker** to get started quickly and work efficiently within the monorepo.

## Project Structure

The project follows a monorepo architecture, allowing multiple applications and shared packages to live in a single repository.

```
.
├── apps/
├── configs/
├── packages/
├── ...
```

## Development

Clone the repository and follow the project-specific setup instructions. Once your environment is ready, use **Docker** as your primary development tool.
